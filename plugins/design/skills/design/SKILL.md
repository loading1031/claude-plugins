# 디자인 문서

근거: ${CLAUDE_SKILL_DIR}/../../docs/design-doc.md. 문서는 Claude Docs 도구로 읽고 쓴다.

프로젝트 `CLAUDE.md`의 "## 디자인" 절(문서 링크, 기준)을 따른다. 절이 없으면 `/design:init`을 안내한다.

- 화면을 구현하기 전에 그 화면 탭을 "기준"의 rev로 읽고(`atRev`), 탭이 넣어 둔 컴포넌트 그림도 읽는다. 문서와 기준이 다르면 어느 쪽을 따를지 사용자에게 묻는다.
- 구현한 커밋 본문에 반영한 탭 rev와 그림 pub을 적는다: `디자인: 대시보드 rev 3, 버튼 pub 2`.
- 문서를 고칠 때 탭 구성을 지킨다: `화면`(최상위) 아래에 화면별 탭과 `컴포넌트`, `컴포넌트` 아래에 컴포넌트별 탭과 `토큰`.
- 화면 탭에는 컴포넌트 그림을 복사해 그리지 않고 컴포넌트 탭의 그림을 embed한다. 컴포넌트를 고치면 넣어 둔 화면에 저절로 반영된다.
- 토큰·컴포넌트의 실제 값은 코드가 기준이다. 문서의 토큰·컴포넌트 탭은 코드를 읽어 고친다. 화면은 문서가 기준이다.
- 그림을 고쳐도 탭 rev는 오르지 않는다. 사용자가 디자인을 확정하면 "기준" 줄을 지금의 탭 rev와 그림 pub으로 고친다.
