# /design:init — 디자인 문서 연결

## 절차

### 1. 문서
- 인자나 CLAUDE.md에 디자인 문서 링크가 있으면 Claude Docs 도구로 읽어 탭 구성을 확인한다. 구성이 `${CLAUDE_SKILL_DIR}/../../docs/design-doc.md`와 다르면 차이를 보여 주고, 탭을 옮길지 묻는다(탭 이동·이름 변경만 하고 내용은 건드리지 않는다).
- 링크가 없으면 새 문서를 만들지 묻는다. 만들면 탭을 이렇게 둔다(하위 탭은 `subtabOf`):
  - `화면`(최상위, 개요: 화면 목록) — 하위에 사용자가 말한 화면별 탭, 그리고 `컴포넌트`
  - `컴포넌트`(개요: 컴포넌트 목록) — 하위에 `토큰`
  - `토큰` — 코드에 `globals.css`의 `@theme`(또는 그에 해당하는 토큰 파일)이 있으면 읽어 색·간격·글꼴·둥글기 표를 채운다. 없으면 비워 둔다

### 2. CLAUDE.md
프로젝트 루트 `CLAUDE.md`에 아래 절이 없으면 추가하고, 있으면 값만 맞춘다. 다른 내용은 건드리지 않는다.

```markdown
## 디자인
- design 플러그인을 따른다 (화면 작업 전 문서를 읽고, 커밋에 rev·pub을 적는다)
- 문서: <링크>
- 기준: <확정한 탭 rev와 그림 pub. 아직 없으면 "없음">
```

### 3. 확인
결과를 요약한다: 문서 링크, 만들거나 옮긴 탭, CLAUDE.md에 쓴 값.
