# Django + HTMX

프로젝트의 실제 HTMX 사용과 버전을 먼저 확인한다. [HTMX 규칙](../../docs/conventions/htmx.md)을 읽고 부분 응답 경계·CSRF·인증·폼 오류를 기존 방식과 연결한다. 필요한 템플릿과 테스트 규칙은 [템플릿](../../docs/conventions/templates.md), [검증](../../docs/conventions/testing.md)에 있다.
