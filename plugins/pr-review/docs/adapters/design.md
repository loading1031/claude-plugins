# Design 리뷰 어댑터

공통 리뷰어는 디자인 플러그인의 원본을 직접 읽는다.

- `plugins/design/skills/design/SKILL.md`
- `plugins/design/docs/design-doc.md`
- 대상 프로젝트 `CLAUDE.md`의 `## 디자인` 및 해당 프로젝트의 승인 문서·컴포넌트 카탈로그

검토 시 변경된 화면·문서와 승인된 IA, 흐름, 와이어프레임, 토큰·컴포넌트 원본을 대조한다. 제품 동작 상태, 빈 값·오류·로딩, 반응형·접근성을 포함해 실제 변경 범위만 검토한다. HTML/JSON/SVG 등 줄 단위 근거가 있으면 해당 PR diff 줄에 연결한다. 렌더링이나 브라우저 상호작용을 직접 확인하지 않았다면 시각 검증은 완료로 표시하지 않는다.
