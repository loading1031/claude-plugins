# PR 리뷰

공통 리뷰 기준은 `${CLAUDE_PLUGIN_ROOT}/docs/review-workflow.md`를 따른다. 코드 검토는 `pr-reviewer` 에이전트에 위임하고, 직접 검토를 요청받은 경우 동일한 절차를 따른다.

## 실행

1. PR 번호, URL 또는 현재 브랜치 중 사용자가 지정한 대상을 식별한다. 지정이 없으면 현재 저장소와 브랜치 상태를 확인하고 임의의 원격 PR을 선택하지 않는다.
2. 리뷰 대상 PR의 base/head, 설명, 변경 파일, 전체 diff를 확인한다.
3. 저장소 지침과 `${CLAUDE_PLUGIN_ROOT}/docs/adapters/README.md`를 따라 관련 플러그인의 원본 스킬·참조 문서를 읽는다.
4. 설계 문서나 UI/템플릿/스타일 변경이 있으면 디자인 기준도 적용한다. 로직과 인터페이스 변경이 UI에 미치는 영향을 검토한다.
5. 관련 테스트와 정적 검사를 살펴본다. 실행은 사용자가 요청했거나 리뷰 정확도에 꼭 필요한 경우에만 수행하고, 실행 여부와 결과를 분리해 보고한다.
6. 발견 사항을 변경 줄에 연결해 PR 리뷰로 작성하거나, 리뷰 API 사용이 불가능하면 파일·라인별 초안을 제공한다.

## 범위 판별

경로는 탐색의 출발점이다. 저장소 지침과 변경의 실제 기술·제품 맥락으로 적용 기준을 결정한다. 하나의 PR에 여러 영역이 있으면 해당 영역별 기준을 모두 적용하고 같은 문제를 중복 보고하지 않는다.
